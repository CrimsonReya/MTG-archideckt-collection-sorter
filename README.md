# What does this do?
Tldr: takes your collection and filters out cards that are used in decks. Useful for when you craft new deck but are unsure which cards are unused.

# Requirements
Python

# Setup
1. Clean collections/decks folders
2. export your collection and decks
3. Export Quantity, Name, and scryfallId all as csv
4. Put your collections in collections folder, decks in decks
5. run `python filter_collection.py`
6. in `filtered` see your new filtered deck with cards that are not being used
7. copy the content of the newest file, and import it into archideckt as new deck
8. Enjoy~
